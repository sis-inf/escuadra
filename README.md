# Escuadra

[![Build Status]][build] [![PyPI]][pypi] [![License]][license]

## Descripción

Escuadra es una suite modular de herramientas orientadas a distintas ramas de la ingeniería. La arquitectura está diseñada bajo el principio de separación de responsabilidades, permitiendo que cada componente cumpla una función específica y sea fácilmente mantenible y escalable.

## Inicio Rápido

```bash
# 1. Clonar el repositorio
git clone https://github.com/tu-organizacion/escuadra.git
cd escuadra

# 2. Instalar en modo editable
pip install -e .

# 3. Ejecutar un cálculo de ejemplo
python -m escuadra.examples.calcular --entrada 100
```

**Salida esperada**

```
Resultado: 212.0
```
