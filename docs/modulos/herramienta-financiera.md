# 💰 Herramienta Financiera

Esta herramienta permite calcular **interés compuesto**, **valor presente** y **valor futuro**, facilitando el análisis de inversiones y préstamos.

---

## 🎯 ¿Qué hace esta herramienta?

La calculadora financiera incluye tres funciones principales:

| Función | Descripción |
|---------|-------------|
| **Valor Futuro (VF)** | Calcula el monto futuro de una inversión o préstamo con interés compuesto |
| **Valor Presente (VP)** | Calcula el valor actual de un monto futuro |
| **Interés Compuesto** | Calcula el interés acumulado sobre una inversión |
