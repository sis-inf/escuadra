Este documento lista todos los módulos disponibles en la documentación. Cada módulo tiene una descripción breve y un enlace a su documentación completa.

## Módulos Planificados

Los siguientes módulos están en desarrollo y se documentarán cuando estén listos:

- `cache-manager`: Gestor de caché eficiente para aplicaciones.
- `notification-service`: Servicio de notificaciones push y email.
- `analytics-integrator`: Integrador de herramientas de análisis.

## Cómo agregar un nuevo módulo

Para agregar un nuevo módulo al índice:

1. Crea el archivo de documentación en `docs/modulos/<nombre-módulo>.md`.
2. Añade una entrada a esta tabla con:
   - Nombre del módulo
   - Descripción breve
   - Lenguaje
   - Número de herramientas
   - Enlace al archivo creado
3. Guarda los cambios y verifica que el enlace funcione.
