## Cómo agregar un nuevo módulo

Para incluir un nuevo módulo en este índice:

1. Crea el archivo de documentación en `docs/modulos/<nombre-módulo>.md`.
2. Añade una entrada a esta tabla con:
   - Nombre del módulo (sin espacios ni guiones).
   - Breve descripción en una línea.
   - Lenguaje usado.
   - Número de herramientas o componentes.
   - Enlace al archivo `.md` creado.
3. Guarda los cambios y verifica que el enlace funcione.

Este índice es la primera página que ven los usuarios nuevos, así que asegúrate de mantenerlo claro y actualizado.
