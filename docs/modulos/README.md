# Índice de Módulos

Este documento proporciona un resumen de todos los módulos disponibles en la documentación. Cada módulo tiene una descripción breve y un enlace a su documentación completa.

## Módulos Disponibles

| Nombre del módulo | Descripción | Lenguaje | Número de herramientas | Documentación |
|-------------------|------------|----------|------------------------|---------------|
| `basic` | Módulo básico para comenzar con el sistema. | TypeScript | 3 | [basic.md](./basic.md) |
| `advanced` | Módulo avanzado con funcionalidades complejas. | JavaScript | 7 | [advanced.md](./advanced.md) |
| `utils` | Conjunto de herramientas útiles para tareas comunes. | Python | 5 | [utils.md](./utils.md) |
| `api` | Documentación de la API principal del sistema. | TypeScript/JavaScript | 12 | [api.md](./api.md) |
| `cli` | Interfaz de línea de comandos para el sistema. | Rust | 4 | [cli.md](./cli.md) |

## Módulos Planificados

Los siguientes módulos están en desarrollo y se documentarán cuando estén listos:

- `database`: Gestión de bases de datos integradas.
- `authentication`: Sistemas de autenticación y autorización.
- `notifications`: Notificaciones push y email integradas.

## Cómo agregar un nuevo módulo

Para agregar un nuevo módulo al índice:

1. Crea el archivo de documentación en `docs/modulos/<nombre>.md`.
2. Añade una entrada en esta tabla con:
   - Nombre del módulo
   - Breve descripción
   - Lenguaje(s) utilizado(s)
   - Número de herramientas
   - Enlace al archivo creado
3. Guarda los cambios y verifica que el índice sea navegable.
